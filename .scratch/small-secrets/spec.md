# 小秘密：来源角色私有记忆

Status: done

GitHub Issue: [#1](https://github.com/Nomikfk1215/eidolon-sc/issues/1)

设计决策：[ADR-Ultra-0001](../../docs/adr/ADR-Ultra-0001-private-memories.md)。实现与验证记录见[实现票 01](issues/01-private-memories.md)。

## 用户场景

用户在设置的记忆页看到「对黛冬優子说的」一条记忆，点击删除按钮左侧的图钉后，条目显示「仅黛冬優子知道」。此后的记忆读取只允许黛冬優子使用这条记忆，其他角色继续读取共享记忆。再次点击图钉恢复共享。

## 实现落点

- `frontend/src/components/MemoriesSettings.tsx`：图钉、范围文案、保存与失败反馈。
- `frontend/src/lib/api.ts`、`backend/src/eidolon/app.py`：记忆返回可见范围，增加修改接口；按当前登录用户校验记忆归属，私有对象由服务端取来源角色。
- `backend/src/eidolon/memory.py`：范围字段迁移、读取过滤、后台提炼与取代规则、并发校验。现有 `(user_id, text)` 去重与取代链需要检查，避免跨范围合并或扩散。
- `backend/src/eidolon/data_package.py`：范围字段与格式版本兼容。
- 实现时同步 `GLOSSARY.md` 中「记忆」与「来源角色」的定义，保留原作者 ADR，以 ADR-Ultra-0001 记录个人规则。

## 验收标准

- [x] 图钉位于垃圾桶左侧，状态和文案能明确表示共享／仅来源角色可知，不改变排序。
- [x] 切换状态由服务端保存，刷新、重新登录和更换设备后保留；保存失败恢复原状态并提示。
- [x] 来源角色可按原有相关性规则检索该记忆，其他角色的候选、重排输入及最终模型上下文均不包含它。
- [x] 文字对话、通话、主动搭话、后台提炼和备用读取路径均遵守范围；保留主动搭话原有的来源角色限制。
- [x] 对私有记忆的补充或取代继续私有；其他角色不能读取或取代该记忆。
- [x] 私有化期间已有候选、缓存或后台任务不会在保存成功后继续以旧共享范围注入或写出派生共享记忆。
- [x] 恢复共享后可按原有规则读取；切换范围不改变取代关系。
- [x] 用户仍可查看、删除全部记忆，修改接口拒绝访问其他用户的条目。
- [x] 旧记忆和旧数据包默认共享；新数据包保留范围，不兼容的旧部署拒绝新格式；导入去重不放宽私有范围。
- [x] 来源角色已移除的私有记忆保持私有，可由用户恢复共享或删除。

## 生效边界

不回溯删除其他角色已有的聊天内容；不自动处理语义相似的其他共享条目；不增加自然语言自动保密、多个私有对象或独立角色记忆库。
